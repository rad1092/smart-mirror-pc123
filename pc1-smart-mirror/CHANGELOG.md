# PC1 변경 이력

이 문서는 `git log`와 현재 작업 내용을 기준으로 PC1이 어떻게 바뀌었는지 정리합니다.

## 2026-05-19

### 연결 구조 정리

- PC1은 PC3만 호출하는 화면 앱으로 정리했습니다.
- PC2 주소, NVIDIA API, DB 연결은 PC1에서 다루지 않습니다.
- 설치 파일을 만들 때 `.env`의 `VITE_PC3_URL`이 포함되므로 PC3 IP가 바뀌면 다시 빌드해야 합니다.

### 프로필 저장 흐름

- 프로필 목록을 PC1 localStorage가 아니라 PC3에서 불러오도록 바꿨습니다.
- 프로필 생성, 수정, 삭제는 PC3 `/api/users/profiles` API로 처리합니다.
- localStorage는 마지막 선택 프로필 id 정도만 캐시합니다.
- 프로필 삭제 후 PC3에서 다시 목록을 불러와 화면을 갱신합니다.

### PC3 계약값 정리

- PC3가 받는 프로필 enum만 전송하도록 정리했습니다.
- 예전 값이 남아 있어도 전송 전에 안전한 값으로 보정합니다.
- 제한 부위의 “없음”은 `none` 문자열이 아니라 빈 배열로 보냅니다.

### 운동 홈 추가

- 프로필을 누르면 운동 홈으로 진입합니다.
- 운동 홈에서 오늘 루틴, 기간 달력, 몸무게 입력, 최근 몸무게 변화, 운동 요약, 최근 코칭 로그를 확인할 수 있게 했습니다.
- 루틴 근거, 코칭 근거, 주간 강도 조절 이유를 PC3 응답 기준으로 표시합니다.
- 루틴이 없을 때는 PC1이 기본 루틴을 만들지 않고 PC3에 새 주간 루틴 생성을 요청합니다.

### 운동 화면 정리

- 카메라 화면의 상단/하단 그라데이션을 제거했습니다.
- 현재 운동, 전체 운동 수, 다음 운동, 휴식 구간을 화면에 표시합니다.
- 운동 중 “이 운동 넘기기”를 추가했습니다.
- 운동 완료 후 코칭 4줄 이상과 근거를 즉시 HUD로 보여주고 결과 화면에도 표시합니다.

### 창 컨트롤

- 상단 호버 컨트롤에 최소화, 닫기, 반 크기 창 전환을 넣었습니다.
- 반 크기 상태에서는 상단 바를 드래그해서 창을 이동할 수 있게 했습니다.

## 최근 커밋 흐름

- `fix: align pc1 profile values with pc3 contract`
  - PC1 프로필 값이 PC3 스키마를 깨지 않도록 enum과 전송값을 정리했습니다.
- `docs: translate pc1 readme to Korean`
  - PC1 README를 한국어로 정리했습니다.
- `feat: prepare pc1 installer branch`
  - 설치 파일 생성 흐름과 브랜치 기반 작업 준비를 했습니다.

## 현재 확인 기준

- `npm run build`가 통과해야 합니다.
- PC1 코드에서 `VITE_PC2`, `PC2_URL`, `localhost:7000`, `127.0.0.1:7000` 직접 호출이 없어야 합니다.
- `.env`, 설치 exe, 스크린샷, 로그 파일은 커밋하지 않습니다.
